# OwoDesk — Plan Comptable OHADA

Page unique, statique et recherchable du **Plan Comptable OHADA (SYSCOHADA révisé)** : 148 comptes avec définition, utilité, exemple d'écriture et recherche instantanée.

Outil gratuit offert par [OwoDesk](https://www.owo.bj/), l'ERP des entreprises africaines.

## Voir en ligne

Après déploiement Vercel : `https://owodesk-plan-comptable.vercel.app`

## Déployer

Aucun build requis — site 100 % statique (`index.html` + `logo.png`).
Sur Vercel : **Add New → Project → Import** ce repo → **Deploy**.
